# Simple Inventory Tracker – Task 30

## Project Overview
This project is part of Task 30 of the Veda Technology Data Analytics Internship. The objective is to create a simple inventory tracking system using Microsoft Excel.

## Objectives
- Track available product stock.
- Set reorder levels for products.
- Identify low-stock items.
- Automatically calculate stock status using IF formulas.
- Generate a low-stock report.

## Tools Used
- Microsoft Excel

## Features
- Inventory management table.
- Automatic stock status calculation.
- Conditional formatting for low-stock items.
- Reorder alerts.
- Low-stock report.
- Inventory summary.

## Outcome
Successfully created an Excel-based inventory tracker that helps monitor product availability and identify products that need restocking.
